# A2: KiCad constraints outside custom DRU rules, and ERC

Work item W2, task A2. Scope: every KiCad constraint that does not come from a `.kicad_dru` custom rule
(board-setup values, board-file setup values, netclass fields, hard-coded implicit rules, item-level
overrides), the DRC error codes and what feeds each one, the DRC test providers, and the schematic ERC
codes, severities and pin-type matrix.

## 0. Sources and conventions

- KiCad source: sparse checkout at GitLab commit `4c23271608ae7fa9e584c6f63b57e54163832c48`
  (2026-11-03). Every `path:line` below is relative to that checkout's root
  (`.../scratchpad/w2/kicad`).
- One file came from outside the checkout: `eeschema/erc/erc_item.cpp` (ERC settings keys and titles)
  is not in the sparse checkout. I fetched it from GitLab at the same commit and cite it as
  `websearch: https://gitlab.com/kicad/code/kicad/-/blob/4c23271608ae7fa9e584c6f63b57e54163832c48/eeschema/erc/erc_item.cpp#L<n>`.
  I extracted only the key and title strings from it.
- Golden boards: `golden-rules/<board>.txt:<line>` (relative to `.../scratchpad/w2/`). The extractor that
  produced them is `scripts/golden_rules.py` in the same directory.
- `unverified (general knowledge; ...)` marks anything I could not check against a file.
- Units: the project JSON stores lengths in mm. The loaders scale them with
  `pcbIUScale.MM_PER_IU` (pcbnew/board_design_settings.cpp:292-294) and the netclass loader with
  `mmToIU` (common/project/net_settings.cpp:44-51). Schematic netclass widths are in mil
  (common/project/net_settings.cpp:54-61, :88-93). Spoke counts are counts. Ratios are fractions
  (1.0 = 100 %).
- Abbreviations used in prose (never in provenance cells): BDS = `BOARD_DESIGN_SETTINGS`,
  provider = a `DRC_TEST_PROVIDER` subclass.

## 9. ERC pin-type conflict matrix

Pin types, in matrix order: I = input, O = output, Bi = bidirectional, 3S = tri-state, Pas = passive,
NIC = not internally connected, UnS = unspecified, PwrI = power input, PwrO = power output,
OC = open collector, OE = open emitter, NC = no connection (eeschema/erc/erc_settings.cpp:45).
Values: `.` = OK, `W` = WARNING (code `ERCE_PIN_TO_PIN_WARNING`), `E` = PP_ERROR
(code `ERCE_PIN_TO_PIN_ERROR`). The matrix is symmetric.

OK (wired-OR).
